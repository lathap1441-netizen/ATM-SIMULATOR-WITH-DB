# ATM Simulator System

## Project Overview
The ATM Simulator System is a Java Dynamic Web Application developed using Java, Jakarta Servlets, HTML, CSS, MySQL, and Apache Tomcat. It performs basic ATM operations through a web interface.

## Features
- User Login
- Deposit Money
- Withdraw Money
- Balance Enquiry
- Mini Statement
- Change PIN
- Logout

## Technologies Used
- Java
- HTML
- CSS
- Jakarta Servlet
- Apache Tomcat 11
- MySQL
- Eclipse IDE

## Software Requirements
- Eclipse IDE
- Apache Tomcat 11
- MySQL Server
- MySQL Connector/J
- JDK 17 or above

## Database
- Database Name: `atmdb`
- Import the `atm.sql` file before running the project.

## Project Structure

```text
src/
 ├── main/
 │   ├── java/
 │   └── webapp/
 └── WEB-INF/
```

## How to Run
1. Import the project into Eclipse.
2. Configure Apache Tomcat 11.
3. Add the MySQL Connector/J JAR.
4. Import `atm.sql` into MySQL.
5. Update the database username and password in `DBConnection.java`.
6. Start Tomcat.
7. Open:

```
http://localhost:6060/ATM_SIMULATOR_DB/login.html
```
